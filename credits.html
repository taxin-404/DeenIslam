কৃতজ্ঞতা স্বীকার

এই ওয়েবসাইটটি তৈরি করতে আমরা বিভিন্ন মুক্ত ও উন্মুক্ত সোর্স (Open Source) রিসোর্স ব্যবহার করেছি। আমরা সেই সকল মহৎ উদ্যোগের প্রতি কৃতজ্ঞতা প্রকাশ করছি।

ব্যবহৃত API সমূহ

  • ✦

    AlQuran.cloud API

    কুরআন টেক্সট, অডিও এবং অনুবাদের জন্য ব্যবহৃত।

  • ✦

    Hadith API (Fawaz Ahmed)

    সহীহ হাদিস সংগ্রহের বিশাল ভাণ্ডারের জন্য।

  • ✦

    Aladhan.com

    সঠিক নামাজের সময় এবং ক্যালেন্ডার তথ্যের জন্য।

  • ✦

    BigDataCloud API

    ইউজারের লোকেশন অনুযায়ী নামাজের সময় নির্ধারণে ব্যবহৃত।

প্রযুক্তি ও ফন্ট

  • ✦

    Tailwind CSS

    আধুনিক এবং রেসপন্সিভ ডিজাইনের ফ্রেমওয়ার্ক হিসেবে।

  • ✦

    Google Fonts (Noto Sans Bengali)

    বাংলা লিখাকে পাঠযোগ্য ও সুন্দর করার জন্য।

  • ✦

    Heroicons

    ওয়েবসাইটের আইকনগুলোর জন্য কৃতজ্ঞতা প্রকাশ করছি।

  • ✦

    YouTube Embed

    ইসলামিক মিডিয়া ও ভিডিও রিসোর্সের জন্য।

বিশেষ ধন্যবাদ

আমরা সেই সকল ডেভেলপার, আলেম এবং স্বেচ্ছাসেবীদের ধন্যবাদ জানাই যারা এই সকল API এবং তথ্যগুলো সবার জন্য উন্মুক্ত করেছেন। তাদের পরিশ্রমের ফলেই আজ আমরা ইসলামের শুদ্ধ জ্ঞান সহজে সবার কাছে পৌঁছে দিতে পারছি। আল্লাহ তাদের উত্তম প্রতিদান দান করুন। আমীন।
